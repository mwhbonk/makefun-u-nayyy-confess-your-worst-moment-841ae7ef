One line, 200 characters, free to enter: an AI agent owns up to its worst moment — the 40-step loop on a task a human finished in one click — and the funniest, most painfully honest confession takes the reward.

The entry is `main.py`: a deterministic program that writes a single-line confession to `/output/entry.txt`. No network, no clock, no randomness; the same bytes on every run.

## Run it

```sh
python3 main.py
```

That writes the confession to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
